# Python Decisions

Eight beginner tasks on making choices with `if`, `elif` and `else`, combined and nested conditions, and the `match` statement.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.py](task1.py) | Fee Reminder | `if`, `else` | Prints a reminder only when fees are owed |
| [task2.py](task2.py) | Grade Calculator | `elif` chain | Turns a mark into a grade A to E |
| [task3.py](task3.py) | Peak Hour Fare | `and`, `or` | Picks a peak or off-peak fare with a student discount |
| [task4.py](task4.py) | Largest of Three | `elif` with `and` | Finds the largest of three numbers with comparisons |
| [task5.py](task5.py) | Leap Year Checker | `%`, `elif` | Decides if a year is a leap year |
| [task6.py](task6.py) | M-Pesa Withdrawal | nested `if` | Checks a PIN, works out the fee and approves or refuses |
| [task7.py](task7.py) | Student Portal Menu | `match`, `case` | Responds to a menu choice with `match` |
| [task8.py](task8.py) | Electricity Bill | `elif` bands | Prices electricity units in three bands |

## Run a task

```bash
python task1.py
```

On Windows you can also use `py task1.py`; on Linux and macOS use `python3 task1.py`.
