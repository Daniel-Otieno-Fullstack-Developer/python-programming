# Python Operators and Expressions

Eight beginner tasks on arithmetic, `//` and `%`, powers, the order of operations, shortcuts such as `+=`, and the logical operators `and`, `or` and `not`.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.py](task1.py) | Simple Calculator | `+ - * / // % **` | Shows all seven arithmetic operators on two numbers |
| [task2.py](task2.py) | Journey Time | `//`, `%` | Splits minutes into hours and minutes |
| [task3.py](task3.py) | Change Machine | `//`, `%` in steps | Breaks an amount into Kenyan notes and coins |
| [task4.py](task4.py) | Number Checker | `%`, `**`, chained `<=` | Tests a number with `%`, `**` and a chained comparison |
| [task5.py](task5.py) | SACCO Savings | `**`, brackets | Works out compound interest on savings |
| [task6.py](task6.py) | CAT Average | brackets, `round()` | Averages three marks and checks for a pass |
| [task7.py](task7.py) | Running Balance | `+=`, `-=` | Updates a balance with `+=` and `-=` |
| [task8.py](task8.py) | Exam Eligibility | `and`, `or`, `not` | Combines conditions with `and`, `or` and `not` |
