# Python Functions

Eight beginner tasks on writing your own functions: parameters, `return`, default and keyword arguments, returning two values and local and global scope.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.py](task1.py) | Welcome Banner | `def`, parameters | Prints a centred banner with a two-parameter function |
| [task2.py](task2.py) | Grade Function | `return` | Returns a grade letter for each of three marks |
| [task3.py](task3.py) | Area Calculator | several functions | Three area functions that return their results |
| [task4.py](task4.py) | Fare With Discount | defaults, keywords | Uses default and keyword arguments for discounts |
| [task5.py](task5.py) | Minimum and Maximum | two return values | Returns the lowest and highest marks together |
| [task6.py](task6.py) | Valid Mark Reader | loop in a function | Validates marks inside a reusable function |
| [task7.py](task7.py) | Scope Explorer | `global`, scope | Shows local and global variables |
| [task8.py](task8.py) | Loan Repayment | function calls a function | Works out a loan's monthly repayment and interest |

## Run a task

```bash

```

On Windows you can also use `py task1.py`; on Linux and macOS use `python3 task1.py`.
