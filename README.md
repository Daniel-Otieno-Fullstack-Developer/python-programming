# Python Programming

Python exercises and worked solutions from the ICT courses I teach at Delhi College, Eastleigh, Nairobi.

The course runs from the first data types through to classes and objects. Each topic folder has eight tasks, each with a tested solution, and the examples use everyday local data: KES prices, matatu fares, M-Pesa balances and class registers.

## Contents

| # | Topic | What it covers | Level |
|---|---|---|---|
| 1 | [Data Types and Variables](Data%20Types%20and%20Variables) | `int`, `float`, `str`, `bool`, `type()`, conversion, `input()`, f-strings | Beginner |
| 2 | [Operators and Expressions](Operators%20and%20Expressions) | Arithmetic, `//` and `%`, `**`, order of operations, `+=`, `and` / `or` / `not` | Beginner |
| 3 | [Decisions](Decisions) | `if`, `elif`, `else`, nested `if`, `match` | Beginner |
| 4 | [Loops](Loops) | `for`, `range()`, `while`, `break`, `continue`, nested loops | Beginner |
| 5 | [Functions](Functions) | Parameters, `return`, default and keyword arguments, scope | Beginner |
| 6 | [Lists and Tuples](Lists%20and%20Tuples) | Indexing, slicing, list methods, searching, sorting, tuples | Beginner |
| 7 | [Strings](Strings) | Slicing, string methods, f-strings, `find()`, `split()`, `join()` | Beginner |
| 8 | [Dictionaries and Sets](Dictionaries%20and%20Sets) | Keys and values, `get()`, counting, nested records, set operations | Beginner |
| 9 | [File Handling and Exceptions](File%20Handling%20and%20Exceptions) | `open()` and `with`, reading and writing files, CSV, `try` / `except` | Intermediate |
| 10 | [Classes and Objects](Classes%20and%20Objects) | Classes, `__init__`, methods, encapsulation, inheritance | Intermediate |

## In each folder

- **README** — what each task does, with sample output.
- **task1.py … task8.py** — a worked solution for each task.
- **Sample data** — the File Handling folder also has the text and CSV files its tasks read.

## Running a task

You need Python 3.10 or newer (the Decisions topic uses `match`). Open a terminal in the topic folder and run:

```bash
python task1.py
```

On Windows you can also use `py task1.py`; on Linux and macOS use `python3 task1.py`.
