# Python Data Types and Variables

Eight beginner tasks on storing values in variables, the `int`, `float`, `str` and `bool` types, converting between them, reading input and printing neat results with f-strings.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.py](task1.py) | Hello, Delhi College | `input()`, `str` | Asks for a name and course, then prints a welcome |
| [task2.py](task2.py) | Student Profile | `int`, `float`, `str`, `bool` | Shows one value of each type next to its `type()` |
| [task3.py](task3.py) | Matatu Fare | `int()`, `*` | Multiplies a fare by trips per week and per month |
| [task4.py](task4.py) | M-Pesa Balance | `float()`, f-strings | Subtracts the amount and a KES 13 charge from a balance |
| [task5.py](task5.py) | Temperature Converter | `float()`, formula | Converts Celsius to Fahrenheit |
| [task6.py](task6.py) | Type Detective | type conversion | Converts one typed value to `int`, `float` and `bool` |
| [task7.py](task7.py) | Shop Receipt | f-string alignment | Prints a receipt with VAT and aligned amounts |
| [task8.py](task8.py) | Age Calculator | `int()`, `bool` | Turns years into months and days and checks for 18+ |
